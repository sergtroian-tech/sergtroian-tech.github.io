Установка за минуту

Никаких установщиков — один файл.

Скачайте

Нажмите «Скачать для Windows» — загрузится «Roblox Launcher+.exe».

Запустите

Если Windows покажет «Защитник Windows предотвратил запуск», нажмите «Подробнее» → «Выполнить в любом случае».

Разрешите

Лаунчер попросит права администратора — они нужны для ускорения Roblox. Это можно выключить в настройках.

Играйте

Войдите в свой аккаунт Roblox и нажмите «Играть».

Вопросы

Это безопасно для аккаунта?

Вход идёт через официальную страницу Roblox. Лаунчер не меняет файлы игры для читов и ничего не встраивает в Roblox — моды меняют только оформление. Данные аккаунтов хранятся зашифрованными.

Почему Windows предупреждает о файле?

У лаунчера нет платной цифровой подписи, поэтому фильтр SmartScreen не знает этот файл. Нажмите «Подробнее» → «Выполнить в любом случае».

Зачем права администратора?

Чтобы поднять приоритет Roblox и включить режим «Высокая производительность». Если не хотите — снимите галочку «Запускать от имени администратора» в «Настройках».

Roblox тормозит или вылетает

Обновите драйвер видеокарты (ссылки выше) и включите «Буст» на вкладке «Играть». Не помогло — напишите в Telegram-поддержку.
